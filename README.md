# Parámetros de resonancia magnética

Guía técnica interactiva de parámetros de imagen por resonancia magnética, con filtrado por categoría y detalles expandibles.

> **EN** · Interactive technical guide to MRI imaging parameters, with category filters and expandable details.

🔗 **Demo:** [parametrosrm.sanidadedtech.es](https://parametrosrm.sanidadedtech.es/)

## Para quién es

Alumnado de T.S. en Imagen para el Diagnóstico y Medicina Nuclear.

## Qué incluye

- Tabla de parámetros de RM
- Filtrado por categoría
- Detalles expandibles

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
